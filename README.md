# 🛍️ ShopSphere — E-Commerce Analytics

> **End-to-end e-commerce analytics project built using Python, MySQL, Excel, and Power BI to analyze customers, sales, products, marketing performance, and delivery operations.**

---

## 📌 Project Overview

ShopSphere is an end-to-end **E-Commerce Analytics project** that transforms raw business data into meaningful insights using data analysis and business intelligence tools.

The project covers the complete analytics workflow, starting from data generation and storage to analysis, visualization, and business decision-making.

The project uses:

- 🐍 **Python** — Data generation and preparation
- 🗄️ **MySQL** — Data storage and SQL analysis
- 📊 **Excel** — Data validation and analysis
- 📈 **Power BI** — Data modeling, DAX, and interactive dashboards
- 🐙 **GitHub** — Project documentation and portfolio

The final solution contains **5 interactive Power BI dashboards** covering different areas of the e-commerce business.

---

# 🎯 Project Objectives

The main objectives of ShopSphere are to:

- Analyze overall business performance
- Understand customer behavior and purchasing patterns
- Identify high-performing products and brands
- Analyze revenue across cities and categories
- Evaluate customer acquisition channels
- Analyze marketing campaign performance
- Measure customer retention and repeat purchases
- Monitor delivery and logistics performance
- Compare delivery partners
- Build interactive dashboards for business decision-making

---

# 💼 Business Problem

An e-commerce business generates large amounts of data from different areas such as:

- Customers
- Products
- Orders
- Payments
- Deliveries
- Marketing campaigns
- Customer acquisition

Analyzing these datasets separately makes it difficult to understand the complete business picture.

ShopSphere brings these areas together to answer important business questions such as:

- Which products generate the most revenue?
- Which customers generate the most value?
- Which cities contribute the most revenue?
- Which acquisition channels perform better?
- How many customers make repeat purchases?
- Which brands perform best?
- How effective are marketing campaigns?
- Which delivery partners perform better?
- Where are delivery delays and cancellations occurring?
